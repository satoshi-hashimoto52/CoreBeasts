# VOLX combat portraits

小型表示で装甲線が潰れる問題を避けるための、ゲーム表示専用VOLXです。
詳細画面の従来立ち絵は置き換えません。

- 用途: バトル、カード、編成枠、履歴、ドラッグ表示、獲得画面
- 解像度: 1024 x 1024、透過PNG
- 色: RED / GREEN / BLUE / RED-BLUE
- 生成方法: OpenAIの画像生成機能で既存VOLXを参照し、輪郭と主要部位を維持したまま内部ディテールを削減
- 後処理: Lanczos方式で1024pxへ縮小し、付加メタデータを除去

## 制約

- 既存VOLXの種族、ポーズ、尖った耳、胸部コア、装甲尾を維持する
- 96〜256pxで顔、コア、脚、尾を識別できる太い輪郭と大きな色面にする
- 背景、影、文字、UI枠を含めない
- 左右反転しても破綻しない構図にする
- 玩具的な強い光沢を避け、暗いバトルUIに合うセル塗りと明確な明暗差にする
- 約2.5頭身のデフォルメとし、頭と胸部を全体の主役にする
- 装甲は大きな色面へ整理し、ネジ、ケーブル、微細なパネル線を描かない
- 発光箇所は両目と胸部コアに限定する
- 濃紺の実機背景でも色面が沈まないよう、装甲の中間階調を明るく保つ

画像生成時は、既存VOLXの種族記号を残しながら、約2.5頭身、大きな頭、広い胸部、短く太い四肢、3枚の尾装甲へ再設計しています。赤版を基準モデルとし、緑・青は同じ形のまま色だけを変更。赤/青は頭・胸部・前脚を赤、後半身・後脚・尾を青に分け、縮小時でも2属性を識別できる構成です。
